# Αυτοματοποιημένος Ταξινομητής Εγγράφων PDF (Email Router)

Ένα έξυπνο backend εργαλείο αυτοματοποίησης σε Python που συνδέεται σε mail servers (IMAP), φιλτράρει αυτόματα τα εισερχόμενα μηνύματα και κατεβάζει αρχεία PDF. 
Το script πραγματοποιεί Text Parsing (εξαγωγή κειμένου) στο περιεχόμενο των εγγράφων και τα ταξινομεί δυναμικά σε υποφακέλους ανάλογα με το περιεχόμενό τους.

## 🚀 Λειτουργίες & Αρχιτεκτονική
- **Email Fetching:** Ασφαλής σύνδεση IMAP και φιλτράρισμα για `UNSEEN` έγγραφα.
- **PDF Text Parsing:** Real-time ανάλυση εσωτερικού κειμένου με τη βιβλιοθήκη `pypdf`.
- **Dynamic File Routing:** Αυτόματη δημιουργία φακέλων και δρομολόγηση αρχείων (π.χ. ξεχωριστοί φάκελοι ανά εταιρεία Cosmote, Vodafone, ΔΕΗ κλπ.).
- **Enterprise Ready:** Ο κώδικας έχει γραφτεί με προδιαγραφές για background execution σε εταιρικά περιβάλλοντα.

## 🛠️ Τεχνολογίες
- Python 3.8+
- `pypdf`
- `imaplib` / `email` / `os`

## ⚙️ Βασική Λειτουργία
1. Εγκατάσταση του `pypdf` (`pip install pypdf`).
2. Ορισμός των keywords στο λεξικό `CATEGORIES` μέσα στον κώδικα.
3. Εκτέλεση: `python automail.py`.

*Σημείωση: Οι προηγμένες ρυθμίσεις για continuous automation στο background (Cron Jobs / Task Schedulers) 
και η enterprise παραμετροποίηση για εταιρικούς servers γίνονται κατόπιν σχετικής παραμετροποίησης.*
